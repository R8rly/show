# SHOW Standard — Cheat Sheet (v2.1)

Inline format: `SHOW S3·H4·O2·W5` · Verified format: `SHOW Verified S3·H4·O2·W5` + Compass mark

## S — Spice (0–6) · *physical explicitness*

| | | |
| :-: | :-- | :-- |
| 0 | Untouched | Kissing only. Door fully closed. |
| 1 | Suggestive | Fade-to-black, implied intimacy. |
| 2 | Open-Door | On-page with discretion. Sensation over anatomy. |
| 3 | Explicit | Anatomically clear, multiple scenes. |
| 4 | Carnal | High-frequency explicit. Intimacy is load-bearing. |
| 5 | Hardcore | Kink, BDSM, power exchange at standard intensity. |
| 6 | Saturated | Explicit intimacy is the dominant content. |

## H — Heat (0–5) · *emotional temperature*

| | | |
| :-: | :-- | :-- |
| 0 | Cool | Romance incidental or absent. |
| 1 | Warm | Affection, light flirtation. |
| 2 | Glowing | Attraction acknowledged. Lingering looks, first kisses. |
| 3 | Burning | Slow-burn intensity. Yearning. |
| 4 | Blazing | Vulnerable confessions, soul-bared scenes. |
| 5 | Wildfire | The relationship is the spine of the story. |

## O — OMG (0–5) · *darkness of tone*

| | | |
| :-: | :-- | :-- |
| 0 | Light | Sweet, cozy, comedy, family. |
| 1 | Shaded | Mild angst, mild peril. |
| 2 | Dim | On-page violence, dark themes with restraint. |
| 3 | Dark | Captivity, stalker, trauma, MC/mafia, war. |
| 4 | Black | Transgressive, dub-con, brutality. |
| 5 | Abyssal | Extreme — content-warning gated. |

## W — WTF (0–10) · *transgression*

| | | |
| :-: | :-- | :-- |
| 0–2 | Vanilla | Conventional, no taboo. |
| 3–4 | Edgy | Mild transgression, age gap. |
| 5–6 | Wild | Step-relationships, captivity-coded, antihero. |
| 7–8 | Unhinged | Strong taboo, dub-con romantically framed. |
| 9–10 | Off the Rails | Non-con as central trope, extreme taboos. |

## Anchors

| Work | S | H | O | W |
| :-- | :-: | :-: | :-: | :-: |
| The Notebook | 1 | 5 | 2 | 1 |
| Fourth Wing | 3 | 5 | 2 | 5 |
| Haunting Adeline | 4 | 4 | 4 | 8 |
| Captive in the Dark | 4 | 3 | 5 | 7 |
| All Quiet on the Western Front | 0 | 1 | 5 | 3 |
| American Psycho | 3 | 1 | 5 | 10 |

**Axes are independent** — no axis modifies any other. Specific content types go in content tags, not axis levels.
